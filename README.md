# Simulate Media Stream Optimization

This Python script simulates the core technical concept behind Opticast: optimizing a media stream to reduce bandwidth usage and improve streaming performance. It generates a high-resolution data stream, applies a basic downsampling optimization, and then simulates streaming both the original and optimized data to compare their sizes and transmission times. This illustrates how optimization algorithms can minimize data transfer while maintaining acceptable 'quality' for low-latency delivery.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
